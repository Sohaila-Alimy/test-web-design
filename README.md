Test Web Design

A simple and creative web design project built with HTML and CSS, focused on clear layouts, easy navigation, and a user-friendly experience.

About the Project

This project is a practice-based web design website created to strengthen my front-end development skills. It includes a homepage, an About page, and a Services page, with styling and images organized in separate folders.

The goal was to practice structuring web pages, applying CSS styles, and creating a consistent design across multiple pages.

Features

- Homepage with a main introduction section
- About page for additional information
- Services page to present services
- Navigation links between pages
- Newsletter subscription section design
- Organized CSS and image folders

Technologies Used

- HTML5
- CSS3

Project Structure

Test-Web-Design/
├── index.html
├── about.html
├── services.html
├── css/
└── images/

How to Run

1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Open "index.html" in your web browser.
4. Use the navigation menu to explore the pages.
